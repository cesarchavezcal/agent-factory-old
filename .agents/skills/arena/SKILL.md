# `/arena` — Multi-Model Implementation Contest

When tackling an algorithmic, performance-critical, or architecture-heavy problem, compare candidate solutions.

## Protocol
1. **Spawn Candidate Branches / Subagents**:
   - Candidate A: Generated by Cursor Composer 2.5.
   - Candidate B: Generated by Grok 4.7 Build-Fast.
2. **Run Identical Verification Suite**: Run `npm test` against both solutions.
3. **Evaluate Rubric**:
   - Benchmark performance / memory usage.
   - Code readability and minimal diff size.
4. **Grafting**: Select the winning candidate, or graft the best parts of Candidate B into Candidate A.
